# Runmio App Store public pages

These files are prepared for the App Store Connect URL requirements.

- `privacy.html` → Privacy Policy URL
- `support.html` → Support URL

Before publishing, replace every `REPLACE_WITH_SUPPORT_EMAIL` with the real support email address. Apple requires the Support URL to lead to real contact information.

Suggested final URLs after hosting:

- `https://YOUR_DOMAIN/runmio/privacy.html`
- `https://YOUR_DOMAIN/runmio/support.html`

The directory is plain static HTML and can be hosted on GitHub Pages, Cloudflare Pages, Netlify, or any HTTPS web host.
