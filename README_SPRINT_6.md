# Running Reminder — Sprint 6.0

UI redesign based on Sprint 5.9 with an iOS 26-inspired liquid-glass visual language.

## Updated UI
- Floating rounded glass tab bar
- Soft mint background with translucent ambient shapes
- Glass dashboard hero, status tiles, activity chart, next-run and current-plan cards
- Glass training plan overview, upcoming workouts and management controls
- Glass calendar
- Settings redesigned as grouped iOS-style glass rows
- Workout cards restyled to match the new visual system

## Preserved from Sprint 5.9
- SQLite local data and schema
- Manual run entry
- Plan editing
- Completed / Skipped / Missed states
- Local notifications
- Vietnamese / English
- iCloud Drive JSON backup / restore
- App icon / splash / onboarding
